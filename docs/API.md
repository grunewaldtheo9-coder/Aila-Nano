# API Reference

Base URL: `http://localhost:8000` (default). Interactive OpenAPI docs are
auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc` when the
server is running.

## `GET /health`

Returns model/runtime status.

```json
{
  "status": "ok",
  "model_loaded": true,
  "num_parameters": 10877184,
  "vocab_size": 8192,
  "device": "cpu",
  "agents": ["general", "programming", "research", "writing"]
}
```

`model_loaded: false` means no trained checkpoint was found and the
server is serving a freshly-initialized (untrained) model — see
`docs/CONFIGURATION.md` for `AILA_CHECKPOINT`.

## `GET /agents`

List all agent personas and their system prompts.

## `GET /agents/{agent_name}`

`404` if `agent_name` isn't one of `general`, `programming`, `research`,
`writing`.

## `POST /chat`

Non-streaming chat turn.

```json
{
  "conversation_id": "conv-abc123",
  "message": "What is a transformer?",
  "agent": "research",
  "settings": {
    "max_new_tokens": 200,
    "temperature": 0.8,
    "top_k": 40,
    "top_p": 0.95,
    "repetition_penalty": 1.15
  },
  "remember_turn": true
}
```

`settings` is optional (falls back to the agent's defaults). Response:

```json
{ "conversation_id": "conv-abc123", "agent": "research", "reply": "..." }
```

## `POST /chat/stream`

Same request body as `/chat`, but responds with
`text/event-stream` (Server-Sent Events):

```
event: token
data: {"delta": "A "}

event: token
data: {"delta": "transformer "}

event: done
data: {"conversation_id": "conv-abc123"}
```

An `event: error` with `{"error": "..."}` is sent instead of `done` if
generation fails mid-stream. Browsers' built-in `EventSource` can't POST
a body, so consume this by reading the `fetch` response body as a stream
and parsing SSE frames manually — see `web/frontend/lib/api.ts::streamChat`
for a reference implementation.

## `GET /memory/conversations`

List all known `conversation_id`s.

## `GET /memory/conversations/{conversation_id}`

Full turn history for a conversation.

## `DELETE /memory/conversations/{conversation_id}`

Clear a conversation's history.

## `POST /memory/remember`

```json
{ "content": "The user prefers concise answers.", "importance": 0.7 }
```

`importance` ∈ [0, 1], default 0.6. Returns `{"id": 17}`.

## `GET /memory/recall?query=...&k=5`

Semantic search over remembered facts, ranked by relevance + recency +
importance (see `memory/ranking.py`).

## `POST /upload`

`multipart/form-data` with a `file` field. Accepts `.txt`, `.md`,
`.jsonl`, `.csv`, `.log` up to 5 MB; chunks the text (~800 chars, 100-char
overlap) and indexes each chunk into the shared knowledge base
(`vectordb.SemanticIndex`, separate from per-user long-term memory).

```json
{ "filename": "notes.txt", "chunks_indexed": 4, "document_ids": [1, 2, 3, 4] }
```
